# 📚 StudyNotion

StudyNotion is a full-stack online learning platform  
where students can learn new skills and instructors can teach online.

This project is built to provide a smooth learning experience  
with secure login, course management and video lectures.

---

## 🌟 What this project does

- Students can create account and login  
- Students can browse different courses  
- Students can buy courses  
- Students can watch video lectures  
- Progress is saved automatically  

- Instructors can create courses  
- Instructors can upload videos  
- Instructors can manage their content  

- Admin can manage users and courses  

---



---

## 🛠 Technologies Used

Frontend:
- React.js
- Tailwind CSS
- Axios

Backend:
- Node.js
- Express.js
- MongoDB

Authentication:
- JWT (JSON Web Token)

Other tools:
- Cloudinary (for file upload)
- Razorpay (for payments)

---

## 🔐 Security

- Secure login system  
- Protected routes  
- Role based access  
  - Student  
  - Instructor  
  - Admin
